# 🧁 Sistema de Doceria — Gestão e Controle de Pedidos

Um sistema web robusto focado no desenvolvimento de Back-end e persistência de dados. A aplicação foi criada para simular a operação real de um pequeno comércio de doces, implementando lógica de programação pura e operações **CRUD** completas para o gerenciamento de produtos e organização de pedidos de forma prática e intuitiva.

> 💡 **Nota de Arquitetura:** Este projeto possui foco exclusivo no desenvolvimento da camada de negócios (Back-end) e manipulação de dados. A interface utiliza HTML semântico puro para priorizar a validação de fluxos de dados, queries de banco de dados e a correta aplicação da lógica estrutural.

---

## 🚀 Funcionalidades e Regras de Negócio

* **📦 CRUD de Produtos:** Cadastro, consulta, atualização e remoção de doces e produtos do catálogo.
* **📋 Controle de Pedidos:** Registro estruturado de pedidos recebidos pelo estabelecimento.
* **🗃️ Organização de Dados:** Fluxo lógico e consistente de informações entre os formulários do usuário e o banco de dados.
* **🛡️ Validação de Fluxos:** Processamento e sanitização de requisições de formulários no lado do servidor.

---

## 🛠️ Tecnologias Utilizadas

O núcleo do projeto foi construído utilizando ferramentas clássicas para o desenvolvimento de sistemas dinâmicos:

* **Back-end:** PHP (Processamento lógico estruturado, gerenciamento de requisições HTTP e rotas).
* **Banco de Dados:** MySQL (Estrutura relacional, armazenamento seguro e consultas estruturadas).
* **Front-end:** HTML5 Puro (Estruturação semântica e interfaces de formulários limpas).

---

## 📦 Como Executar o Projeto Localmente

Para rodar este sistema, você precisará de um ambiente de desenvolvimento local capaz de interpretar PHP e gerenciar bancos de dados MySQL (como o **XAMPP**, **WampServer** ou **Laragon**).

### Passos para Configuração:

1. Na página principal deste repositório, clique no botão verde **"Code"** e escolha **"Download ZIP"**.
2. Extraia o conteúdo do arquivo compactado dentro do diretório do seu servidor local (ex: `C:/xampp/htdocs/` no XAMPP).
3. Abra o seu painel de gerenciamento do banco de dados (ex: `http://localhost/phpmyadmin`).
4. Crie um novo banco de dados vazio (ex: `sistema_doceria`).
5. Importe o arquivo `.sql` que está incluso na pasta do projeto para subir automaticamente a estrutura das tabelas.
6. Ajuste os parâmetros de credenciais (usuário e senha do banco) no seu arquivo de conexão PHP de acordo com o seu servidor local.
7. Abra o navegador e acesse: `http://localhost/sistema-doceria/`
